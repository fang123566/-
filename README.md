# 解码徽派民居 | 徽派建筑文化信息交互可视化展示

本项目是一个以徽派建筑文化为主题的多页面交互式展示网站，围绕宏村、西递等徽州传统聚落中的空间形制、建筑构件、宗族文化、三雕艺术、遗产保护与跨文化传播进行可视化叙事。

网站采用静态前端实现，结合图文叙事、数据图表、翻页书册、互动问答、三维/模型展示、擦拭修复、热点卡片与一键中英切换等交互方式，呈现徽派民居的空间密码与文化传承。

## 技术栈

- **HTML5** — 多页面语义化结构
- **CSS3** — 响应式布局、动画、卡片、翻页与沉浸式视觉效果
- **JavaScript (ES6+)** — 原生交互逻辑、动态内容渲染与状态控制
- **ECharts 5** — 建筑文化数据可视化图表
- **Three.js / 模型资源** — 局部页面中的建筑模型与空间展示
- **i18n.js** — 自定义中英双语切换字典与动态翻译引擎

## 核心功能

- **沉浸式首页**：背景视频、云粒子动效、视觉引导与入口导航
- **交互热点卡片**：点击或悬浮查看建筑局部、文化解释与地点信息
- **知识问答**：动态题目、选项、答案解析与最终评分反馈
- **翻页书册**：天井页面以书页形式展示长篇文化叙事
- **数据图表**：基于 ECharts 的类型分布、年代分布、雷达图、趋势图等
- **三雕展示**：纹样、题材、寓意与构件关系的图文交互
- **保护互动**：古建修复案例、前后对比与擦拭式修复体验
- **响应式设计**：适配桌面端与常见浏览器窗口尺寸
- **一键中英切换**：通过导航中的语言按钮切换全站可见文本

## 国际化说明

项目的中英双语功能由 `i18n.js` 实现：

- `NAV_DICT`：导航栏与通用导航文本
- `COMMON_DICT`：页脚、公共按钮与跨页面通用文本
- `PAGE_DICT`：各页面专属文本、动态卡片、问答、图表、翻页书册等内容
- `MutationObserver`：监听动态插入或更新的 DOM 文本，确保卡片、弹窗、问答和书页内容也能被翻译

切换语言后，网站会将当前语言状态保存到 `localStorage`，刷新或跳转页面后仍保持当前语言。

## 本地运行

推荐使用静态服务器运行，避免浏览器本地文件安全策略影响视频、模型或动态资源加载。

```bash
npx http-server . -p 3001 -c-1
```

然后访问：

```text
http://localhost:3001
```

如果端口 `3001` 被占用，可改用其他端口：

```bash
npx http-server . -p 3002 -c-1
```

也可以直接在浏览器中打开 `index.html`，但部分视频、模型或跨文件资源可能无法正常加载。

## 构建与部署

项目提供静态构建脚本：

```bash
npm run build
```

构建产物默认输出到：

```text
dist/
```

本地预览构建产物：

```bash
npm run serve
```

项目已包含 `vercel.json`，可部署到 Vercel：

- **Build Command**：`npm run build`
- **Output Directory**：`dist`

## 开发提示

- 修改页面可见中文后，若需要支持英文切换，应同步在 `i18n.js` 中添加翻译键值
- 动态生成的文本应尽量保持完整、稳定，方便翻译字典精准匹配
- 新增页面时，需要在导航、页面字典与公共样式中同步维护
- 大型素材建议放入 `public/` 或 `素材/`，并注意路径大小写与部署后的相对路径

## 项目定位

本网站适用于徽派建筑文化展示、非遗数字化传播、课程设计、文化可视化作品集与交互叙事展示等场景。
